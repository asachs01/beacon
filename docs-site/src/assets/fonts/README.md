# Docs fonts

Self-hosted so the docs make no third-party font requests. These are the same
latin variable-weight files the app loads in `src/fonts/load.ts`, from
`@fontsource-variable/fraunces` 5.3.0 and `@fontsource-variable/inter` 5.3.0.

- `fraunces-latin-wght-normal.woff2`: headings (`--font-family-heading` in `src/styles/tokens.css`)
- `inter-latin-wght-normal.woff2`: body (`--font-family-body` in `src/styles/tokens.css`)

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
