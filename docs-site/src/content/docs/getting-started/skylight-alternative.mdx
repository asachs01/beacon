# A free Skylight Calendar alternative that runs on Home Assistant

Beacon is a free, MIT-licensed Skylight Calendar alternative that installs as a Home Assistant add-on and runs in any tablet's browser or as a signed Android app. You get a shared calendar, chores, lists, and photos on a tablet you already own, without buying a Skylight display or paying for [Calendar Plus at $79/year](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost). Beacon has an [in-app meal planner](/docs/features/meals/) ([v1.48.0](https://github.com/asachs01/beacon/releases/tag/v1.48.0)) with a week grid for breakfast, lunch, dinner, and snacks (it follows Settings → General → Week Starts On), an editable dashboard Menu card (including on empty days), and Beacon recipes. Add ingredients to grocery list writes to the default list or the built-in Shopping List, including Home Assistant to-do lists, not Grocy.

For Hearth Display and DAKboard as well as Skylight, see [Beacon vs Skylight Calendar, Hearth, and DAKboard](/docs/getting-started/compare/).

[Calendar Plus is $79/year](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost) for [meal planning, recipes, rewards, photo screensaver, and Magic Import](https://skylight.zendesk.com/hc/en-us/articles/57326775089691-Calendar-Plus) | $0 |
| Meals | [Meal planning is a Calendar Plus feature](https://myskylight.com/products/skylight-calendar): plan breakfast, lunch, dinner, and snacks and add them to the calendar; Plus also covers uploading or entering recipes, and creating new ones with Smart technology. | [In-app meal planner](/docs/features/meals/) ([v1.48.0](https://github.com/asachs01/beacon/releases/tag/v1.48.0)): week grid for breakfast, lunch, dinner, and snacks (follows Settings → General → Week Starts On); editable Menu card (including on empty days); Beacon recipes. Add ingredients to grocery list writes to the default list or the built-in Shopping List, including Home Assistant to-do lists, not Grocy. MCP `beacon_set_meal_plan` merges by default; a null or empty name clears one slot; `replace: true` replaces the whole plan. |
| Photos | [Photo/video screensaver requires Calendar Plus](https://skylight.zendesk.com/hc/en-us/articles/57326775089691-Calendar-Plus) | Included; see [Photos](/docs/features/photos/) |
| Magic Import | [Calendar Plus includes Magic Import](https://myskylight.com/products/skylight-calendar): forward emails and PDFs, or upload photos of lists and flyers | [Magic Import](/docs/features/magic-import/) ([v1.49.0](https://github.com/asachs01/beacon/releases/tag/v1.49.0)): paste text, or add one photo or PDF (JPEG, PNG, HEIC where the browser can convert it, or PDF; 10 MB). A PDF with real text is read in the browser (first 5 pages) and follows the pasted-text path (Home Assistant conversation agent, or a local parser). Only photos and scanned PDFs (page 1 of a scan) need the Home Assistant AI Task entity you pick in Settings → Display → Magic Import: AI Task entity for photos (Home Assistant 2025.8 or newer). The local parser can't read images, and a failed photo read does not fall back to it. Beacon does not write the file to its own /data; it briefly uploads it to Home Assistant's local media source for the task and deletes it afterward. A cloud AI Task sends the file to that provider. Beacon does not import forwarded email, so this mostly closes the gap, not fully. |
| Night mode | [Sleep Mode](https://myskylight.com/products/skylight-calendar) is listed as a standard feature: the screen goes to sleep and wakes on a schedule. [Skylight Calendar support](https://skylight.zendesk.com/hc/en-us/articles/37235485034779-Sleep-Mode) says Sleep Mode disables the screen, can be scheduled or started manually, and a tap turns the screen back on. | [Night mode](/docs/features/night-mode/) ([v1.50.0](https://github.com/asachs01/beacon/releases/tag/v1.50.0)): Off by default under Settings → Display → Night mode, with a schedule (default 9:00 PM to 6:30 AM, overnight ranges work, device local time) and a manual on/off. While it is on, Beacon switches to the Midnight theme, adds a dim layer (default 30%), and can show an optional clock-only screen. A tap removes the dim layer and the clock-only screen for 60 seconds, so the dashboard is back at full brightness, still in the Midnight theme. The dimming is a web overlay; it does not change the device's screen brightness. A finished countdown timer wakes the screen and holds it until the alarm is dismissed. Night mode also runs on the Kid Display and kiosk views when it is turned on. |
| Guest mode | [Parental Lock](https://myskylight.com/products/skylight-calendar) is listed as a standard feature: it prevents editing, adding, or deletion of events and chores. [Skylight Calendar support](https://skylight.zendesk.com/hc/en-us/articles/36835387462555-General-Settings) says it uses a device-specific 4-digit PIN, can require the PIN to add or modify events and tasks, and can re-lock after 1 to 10 minutes of inactivity. Skylight Calendar does not list a guest mode. | [Guest mode](/docs/features/guest-mode/) ([v1.51.0](https://github.com/asachs01/beacon/releases/tag/v1.51.0)): Optional guest PIN, empty by default, under Settings → Display → Guest mode. A guest enters with the corner gesture plus that PIN, and a Guest badge stays on the screen. Guests can view the calendar, check off chores, add to the grocery list, and use timers. They can view events but cannot create, edit, or delete them, and they cannot change settings or approve imports. What is hidden is a deny-list: whereabouts features (presence and location) and calendars marked Hide from guests are hidden; meals, photos, music, and the leaderboard stay visible. Guest check-offs on a family member's chore earn points and streaks and show "Checked off by Guest" on chore rows (the Chores screen, and completed chore rows on the dashboard and calendar task lists). Home Assistant to-do items don't get the label. From [v1.52.0](https://github.com/asachs01/beacon/releases/tag/v1.52.0), an unassigned guest check-off is recorded as Guest and earns no points. Guests can earn rewards but cannot redeem them. A session ends with the family PIN, the guest PIN when no family PIN is set, the timeout (default 4 hours), or when the guest PIN is cleared or changed. Leaving kiosk or Kid Display is a separate step. Guest mode is not a security boundary: it only limits what this Beacon screen shows. |
| Grocy | not listed | [Grocery](/docs/features/grocery/) ([v1.52.0](https://github.com/asachs01/beacon/releases/tag/v1.52.0)): Optional, through the [HACS Grocy integration](https://github.com/custom-components/grocy), under Settings → Integrations → Grocy. Magic Import can add items to Grocy's shopping list (`add_generic`). Optional expiring-products and low-stock cards (off by default) read `binary_sensor.grocy_expiring_products` and `binary_sensor.grocy_missing_products`. From 1.52.1, with Grocy Integration on, the Grocery screen includes a list named Grocy and check-offs on that list write the shopping-list done flag. The expiring card shows only items due within 3 days. |
| Home sensors | not listed | [Home sensors](/docs/features/home-sensors/) ([v1.53.0](https://github.com/asachs01/beacon/releases/tag/v1.53.0)): Off by default. Pick entities under Settings → Integrations (each can have a friendly name and icon), then add the card in dashboard edit mode. It is not in the Family, Classic, or Compact layouts. Values update live over the Home Assistant websocket, with no polling. If an entity is unavailable, unknown, or hasn't updated in 3 hours, the card shows "Unavailable", "Unknown", or "No update in 3 h" instead of a stale value. The card shows only the entities you pick, and it excludes cameras. The card is read-only: it does not toggle devices, call services, or show camera feeds. The `/beacon-ws/ha` server connection only passes `get_states`, `state_changed` subscriptions, `unsubscribe_events` for subscriptions it opened, and `ping`; other commands are refused. Hidden from guests and Kid Display. Works with the add-on and standalone (`HA_URL`/`HA_TOKEN`). |
| Hardware platform | Skylight's display, plus a [free mobile app](https://myskylight.com/products/skylight-calendar) | Any tablet's browser, or a [signed Android APK from GitHub releases](/docs/getting-started/android/) (sideload; not on Play Store yet), as a Home Assistant add-on or standalone |

## Custom fonts

Beacon lets you choose separate heading and body typefaces in Settings → Appearance. Built-in faces (including dyslexia-friendly Atkinson Hyperlegible and rounded Nunito) are bundled in the app and work offline, including through Home Assistant ingress. You can also enter a Google Fonts family name (needs internet) or upload a `.woff2` file (stored on that device, works offline). See the [Fonts](/docs/customization/fonts/) guide.

## Who should buy Skylight

You want a sealed consumer product, don't run a home server, and prefer support from a hardware vendor.

## Who should install Beacon

You already run (or will run) Home Assistant, want a wall tablet without a subscription, and care about local control. Or you want the same dashboard without HA via standalone mode.

## Replace a Skylight-style setup in about 10 minutes

1. Install Beacon as a Home Assistant add-on (or run standalone).
2. Connect your HA calendar entities (or use the built-in local calendar).
3. Add family members, pick a theme, mount any tablet in the kitchen.

## FAQ

**Is Beacon a Skylight alternative?**
Yes — same wall-display family calendar job, open source and self-hosted.

**Does Beacon require a subscription?**
No. MIT licensed, no cloud account required for core use.

**Do I need Home Assistant?**
Recommended for the richest integration. Standalone mode works with local calendars, lists, and tasks.

**What tablet works?**
Any browser-capable wall tablet or spare screen. Point it at Beacon's URL (or open via HA sidebar / direct add-on URL). On Android you can also [sideload the signed APK from GitHub releases](/docs/getting-started/android/) (not on Play Store yet).

**Is the "Skylight" theme the Skylight product?**
No. It's a visual theme inspired by that clean bright look — not affiliated with Skylight.
