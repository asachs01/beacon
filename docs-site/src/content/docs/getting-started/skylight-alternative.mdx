# A free Skylight alternative that runs on Home Assistant

Beacon is a free, MIT-licensed Skylight Calendar alternative that installs as a Home Assistant add-on and runs in any tablet's browser or as a signed Android app. You get a shared calendar, chores, lists, and photos on a tablet you already own, without buying a Skylight display or paying for [Calendar Plus at $79/year](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost). Beacon has an [in-app meal planner](/docs/features/meals/) ([v1.48.0](https://github.com/asachs01/beacon/releases/tag/v1.48.0)) with a week grid for breakfast, lunch, dinner, and snacks (it follows Settings → General → Week Starts On), an editable dashboard Menu card (including on empty days), and Beacon recipes. Add ingredients to grocery list writes to the default list or the built-in Shopping List, including Home Assistant to-do lists, not Grocy.

For Hearth Display and DAKboard as well as Skylight, see [Beacon vs Skylight, Hearth, and DAKboard](/docs/getting-started/compare/).

## Custom fonts

Beacon lets you choose separate heading and body typefaces in Settings → Appearance. Built-in faces (including dyslexia-friendly Atkinson Hyperlegible and rounded Nunito) are bundled in the app and work offline, including through Home Assistant ingress. You can also enter a Google Fonts family name (needs internet) or upload a `.woff2` file (stored on that device, works offline). See the [Fonts](/docs/customization/fonts/) guide.

## Who should buy Skylight

You want a sealed consumer product, don't run a home server, and prefer support from a hardware vendor.

## Who should install Beacon

You already run (or will run) Home Assistant, want a wall tablet without a subscription, and care about local control. Or you want the same dashboard without HA via standalone mode.

## Replace a Skylight-style setup in about 10 minutes

1. Install Beacon as a Home Assistant add-on (or run standalone).
2. Connect your HA calendar entities (or use the built-in local calendar).
3. Add family members, pick a theme, mount any tablet in the kitchen.

## FAQ

**Is Beacon a Skylight alternative?**
Yes — same wall-display family calendar job, open source and self-hosted.

**Does Beacon require a subscription?**
No. MIT licensed, no cloud account required for core use.

**Do I need Home Assistant?**
Recommended for the richest integration. Standalone mode works with local calendars, lists, and tasks.

**What tablet works?**
Any browser-capable wall tablet or spare screen. Point it at Beacon's URL (or open via HA sidebar / direct add-on URL). On Android you can also [sideload the signed APK from GitHub releases](/docs/getting-started/android/) (not on Play Store yet).

**Is the "Skylight" theme the Skylight product?**
No. It's a visual theme inspired by that clean bright look — not affiliated with Skylight.
