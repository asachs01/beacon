# Beacon vs Skylight, Hearth Display, and DAKboard

Beacon is a free, MIT-licensed family command center that installs as a Home Assistant add-on and runs in any tablet's browser or as a signed Android app. Skylight Calendar and Hearth Display are dedicated wall displays with paid plans for many family features, and DAKboard is a hosted screen service with a free plan and paid Essential and Plus tiers.

Competitor prices and plan details below were checked against each company's own site or help center on November 22, 2026 (America/New_York). They can change. Every competitor claim is linked to its source. Claims that could not be verified are left out. For a shorter Skylight-only write-up, see [Beacon vs Skylight Calendar](/docs/getting-started/skylight-alternative/).

## Beacon

Beacon is free and open source under the [MIT license](https://github.com/asachs01/beacon/blob/main/LICENSE). It installs as a [one-click Home Assistant add-on](/docs/getting-started/installation/), and it also runs standalone in Docker. You can open it in any tablet's browser, or install a [signed Android APK from GitHub releases](/docs/getting-started/android/) (sideload; not on Play Store yet).

It includes a shared calendar, chores, photos, custom fonts, and translations in nine languages (English, German, Spanish, French, Italian, Japanese, Korean, Dutch, and Portuguese). Chores can optionally [turn on a Home Assistant switch, input_boolean, light, or fan](/docs/features/chore-privileges/) when a child finishes today's list, and the add-on fires `beacon_chore_completed` and `beacon_all_chores_done` events for automations. You can also [hold a button on the wall to talk to Home Assistant Assist](/docs/features/press-to-talk/) and check off chores by voice. The microphone needs HTTPS or localhost. You can [paste a school email or other text, or add one photo or PDF](/docs/features/magic-import/) ([v1.49.0](https://github.com/asachs01/beacon/releases/tag/v1.49.0)) to draft calendar events and list items, then approve them with the family PIN. Pasted text, and a PDF with real text (read in the browser, first 5 pages), is processed by your Home Assistant conversation agent, or a local parser. If that agent is a cloud service (OpenAI, Google, or Anthropic), Home Assistant sends the text to that provider. Only photos and scanned PDFs (page 1 of a scan) need the Home Assistant AI Task entity you pick in Settings → Display → Magic Import: AI Task entity for photos (Home Assistant 2025.8 or newer). The local parser can't read images, and a failed photo read does not fall back to it. Beacon does not write the file to its own /data; it briefly uploads it to Home Assistant's local media source for the task and deletes it afterward. A cloud AI Task sends the file to that provider. Beacon does not import forwarded email, so this mostly closes the gap with Skylight Calendar's Magic Import, not fully. There is an [in-app meal planner](/docs/features/meals/) ([v1.48.0](https://github.com/asachs01/beacon/releases/tag/v1.48.0)) with a week grid for breakfast, lunch, dinner, and snacks (it follows Settings → General → Week Starts On), and the dashboard Menu card is editable even on empty days. Meals can use a Beacon recipe. Add ingredients to grocery list writes to the default list or the built-in Shopping List, including Home Assistant to-do lists, not Grocy. The MCP tool `beacon_set_meal_plan` merges by default; a null or empty name clears one slot, and `replace: true` restores the old replace-everything behavior. You can still fill the plan from the AnyList sync. You can turn on [Night mode](/docs/features/night-mode/) ([v1.50.0](https://github.com/asachs01/beacon/releases/tag/v1.50.0)) under Settings → Display to switch to the Midnight theme and add a dim layer on a local schedule, or turn it on or off manually. A tap removes the dim layer and the clock-only screen for 60 seconds, so the dashboard is back at full brightness, still in the Midnight theme. The dimming is a web overlay; it does not change the device's screen brightness. A finished countdown timer wakes the screen and holds it until the alarm is dismissed. You can turn on [Guest mode](/docs/features/guest-mode/) ([v1.51.0](https://github.com/asachs01/beacon/releases/tag/v1.51.0)) with an optional guest PIN under Settings → Display, empty by default. A guest enters with the corner gesture plus that PIN. Guests can view the calendar, check off chores, add to the grocery list, and use timers, but they cannot create, edit, or delete events, change settings, or approve imports. Guest mode is not a security boundary: it only limits what this Beacon screen shows. With the [HACS Grocy integration](https://github.com/custom-components/grocy), [Magic Import](/docs/features/magic-import/) can add items to Grocy ([v1.52.0](https://github.com/asachs01/beacon/releases/tag/v1.52.0)), and optional expiring and low-stock cards are available under Settings → Integrations → Grocy. From 1.52.1, with Grocy Integration on, the Grocery screen includes a list named Grocy and check-offs on that list write the shopping-list done flag. The expiring card shows only items due within 3 days. You can turn on a read-only [Home sensors](/docs/features/home-sensors/) ([v1.53.0](https://github.com/asachs01/beacon/releases/tag/v1.53.0)) card under Settings → Integrations, then add it in dashboard edit mode. It is off by default and is not in the Family, Classic, or Compact layouts. Values update live. If an entity is unavailable, unknown, or hasn't updated in 3 hours, the card shows "Unavailable", "Unknown", or "No update in 3 h" instead of a stale value. The card does not toggle devices, call services, or show camera feeds, and it is hidden from guests and Kid Display. Data stays on your Home Assistant instance or your own server. See the [installation guide](/docs/getting-started/installation/) and the [Fonts](/docs/customization/fonts/) page.

## Skylight Calendar

[Skylight Calendar](https://myskylight.com/products/skylight-calendar) is sold as a dedicated wall display. Skylight's help center says [hardware pricing varies by model and retailer](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost), and the store currently lists models such as the 15-inch Calendar 2 and the 27-inch Calendar Max.

You do [not need a subscription for basic use](https://skylight.zendesk.com/hc/en-us/articles/36009559376795-Does-Skylight-Calendar-require-a-subscription). Without Plus you can add and sync calendar events, keep track of chores and routines, and make lists. [Calendar Plus costs $79 per year](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost) and unlocks [meal planning and recipes, chore rewards, a photo/video screensaver, and Magic Import](https://skylight.zendesk.com/hc/en-us/articles/57326775089691-Calendar-Plus).

A more detailed Skylight-only page lives at [Beacon vs Skylight Calendar](/docs/getting-started/skylight-alternative/).

## Hearth Display

[Hearth Display](https://hearthdisplay.com/products/hearth-display) is a 27-inch wall display. Hearth's product page lists the display at $699 (sale pricing may apply) and describes a Family Membership billed [from $5.76/month with multi-year plans to $9/month billed monthly](https://hearthdisplay.com/products/hearth-display). The first month is included, and [you can cancel during the trial to avoid being charged](https://hearthdisplay.com/pages/membership).

[Every display includes a shared calendar, Google, iCal, and Outlook syncing, and unlimited profiles](https://hearthdisplay.com/products/hearth-display). If you cancel the membership, [the calendar, calendar syncing, and unlimited profiles keep working](https://hearthdisplay.com/products/hearth-display). The membership adds [Hearth Helper, routines, to-dos, meal planning, stars and rewards, the companion app, and future software updates](https://hearthdisplay.com/products/hearth-display).

## DAKboard

[DAKboard](https://dakboard.com/c/family/) turns a screen you already own — or a DAKboard wall display — into a family calendar and photo board. [A free plan is always available](https://dakboard.com/pricing): one predefined screen, up to two calendars, photos, weather, news/RSS, and TouchHub, with DAKboard branding. [Essential is $5 per month billed annually](https://dakboard.com/pricing) (two custom screens included) and adds custom layouts, up to five calendars, integrations, templates, and custom CSS. [Plus is $8 per month billed annually](https://dakboard.com/pricing) and adds unlimited calendars, a media library, screen loops, scheduling, and faster updates.

You can [connect a Home Assistant dashboard on every plan, including Free](https://dakboard.com/c/family/). That is a dashboard shown on the DAKboard screen, not a Home Assistant add-on. [The built-in Family Chores Manager requires an Essential or Plus plan](https://dakboard.com/c/family/). DAKboard can [display meal plans from tools such as Plan to Eat and Nutrislice](https://dakboard.com/c/family/).

## Which one fits

- **Choose Beacon** if you already run Home Assistant (or will), want a free MIT-licensed dashboard, and prefer to use a tablet you already have.
- **Choose Skylight** if you want a sealed consumer display and are comfortable buying their hardware, with [Plus at $79/year](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost) for meals, photos, and other extras.
- **Choose Hearth** if you want their 27-inch display and Family Membership software as a packaged product.
- **Choose DAKboard** if you want a hosted, highly customizable screen layout, and you are fine with their [free or paid plans](https://dakboard.com/pricing).
