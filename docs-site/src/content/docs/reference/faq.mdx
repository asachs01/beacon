# Frequently Asked Questions

---

## Quick answers

### What is Beacon?

Beacon is a free, open-source family command center for a wall-mounted tablet or spare screen. It shows your shared calendar, chores, today's meals, lists, photos and weather, and runs on your own network as a Home Assistant add-on or a Docker container.

### How much does Beacon cost?

**Nothing.** Beacon is free and MIT-licensed, with no subscription, premium tier or account. Your only costs are a display (a tablet you already own works) and whatever runs Home Assistant or Docker.

### How is Beacon different from Skylight?

Skylight sells its own screen, and meal planning, photos and some other features need Calendar Plus (about $79 a year). Beacon runs on any tablet's browser, keeps your data on your network, and has no paid tier. The trade-off is that you set it up yourself. See [Beacon vs Skylight](/docs/getting-started/skylight-alternative/).

### Which tablets work?

**Any tablet or screen with a modern web browser.** Popular picks are an Amazon Fire HD, a Samsung Galaxy Tab or a Lenovo Tab, usually with Fully Kiosk Browser on Android. An old monitor with a Raspberry Pi works too. See [Deployment](/docs/getting-started/deployment/) for hardware with prices.

### Does Beacon work offline?

**Mostly.** Beacon runs entirely on your local network and never needs its own cloud service. The display keeps a local copy of its data, and the built-in fonts and themes need no internet. Anything that comes from the internet still needs it: Google Calendar sync and weather reach you through Home Assistant, and Google Fonts are downloaded when you pick one.

### Is my family's data private?

**Yes.** Beacon talks only to your Home Assistant instance and its own server on your network. There's no telemetry, analytics or Beacon account. See [Does Beacon send my data anywhere?](#does-beacon-send-my-data-anywhere)

### How do I update Beacon?

On the add-on, go to **Settings → Add-ons → Beacon** and click **Update**. For Docker, rolling back, and fixing a failed update, see [Updating and Troubleshooting](/docs/getting-started/updating/).

## General

### Does this work with Google Calendar?

**Yes.** Beacon reads calendar data through Home Assistant's Google Calendar integration. Set up the integration once in HA, and Beacon automatically discovers your calendars. See the [Getting Started guide](/docs/getting-started/installation/) for step-by-step instructions.

Beacon also works with **any calendar source** Home Assistant supports, including CalDAV (Nextcloud, iCloud, Fastmail), ICS feeds, and the built-in Local Calendar.

### Can I create and edit events from the display?

**Yes.** Beacon supports full CRUD operations on calendar events. Tap the + button or a time slot to create events. Tap an existing event to edit or delete it. You can even drag events to reschedule them. See [Calendar](/docs/features/calendar/).

### Can Beacon add events from a text or email I paste in?

**Yes.** Pasted text needs Beacon **1.47.0** or later. Photos and PDFs need Beacon **1.49.0** or later, and Home Assistant **2025.8** or newer. Open **Import** on the dashboard or calendar, paste the text or add one photo or PDF, review the drafts, and approve them with a family PIN when one is set. Skylight Calendar's Calendar Plus Magic Import can also take forwarded emails; Beacon still does not, so that gap is not fully closed. What sets Beacon's apart is that it is free, approved with the family PIN, and pasted text (and text PDFs) can use a local parser. The paste and review screens name the Home Assistant conversation agent or AI Task entity and its entity id, and label it local, cloud, or may be cloud. Pasted text is processed by your Home Assistant conversation agent, or a local parser. Photos and scanned PDFs are processed by your Home Assistant AI Task entity. A cloud AI Task entity sends the file to that provider. **Settings → Display → Magic Import: use Home Assistant conversation agent** is on by default; turning it off forces the local parser and turns photo and scan import off. **Magic Import: AI Task entity for photos** is empty until you pick an `ai_task` entity. Beacon itself sends the text nowhere, and sends the file nowhere else. See [Magic Import](/docs/features/magic-import/).

### Does Beacon send my data anywhere?

**No, with one caveat.** Beacon itself sends nothing to outside servers. It runs on your local network and talks only to your Home Assistant instance. There is no telemetry, analytics, or cloud dependency of Beacon's own.

The exception is [Magic Import](/docs/features/magic-import/). Only if Magic Import is on, and your Home Assistant conversation agent is a cloud service, does Home Assistant send the pasted text to that provider. A photo or scanned PDF is processed by your Home Assistant AI Task entity. Beacon itself sends the file nowhere else. It briefly uploads the file to Home Assistant's local media source for the task and deletes it afterward, and the review screen tells you if that delete fails. If that entity is a cloud service, Home Assistant sends the file to that provider. To force the local parser, turn off **Settings → Display → Magic Import: use Home Assistant conversation agent**. That also turns photo and scan import off. The AI Task entity for photos is empty until you choose one.

Data flow: `Google/CalDAV -> Home Assistant -> Beacon (local only)`

### Can I use this without Home Assistant?

**Partly.** Beacon has a standalone mode with its own local calendar, lists and tasks, so it works without Home Assistant. Google Calendar sync, weather, music control and grocery integrations all come through Home Assistant, though, so you'd miss those. [HA OS](https://www.home-assistant.io/installation/) is free and runs on a Raspberry Pi, old PC or virtual machine.

## Hardware

### What hardware do I need?

1. **A Home Assistant instance** (HA OS on a Pi, NUC, or VM)
2. **A display device** with a web browser (any tablet, old monitor + mini PC, etc.)

The cheapest complete setup is a $35 Fire HD 8 with a $15 magnetic mount — under $50.

See [Deployment](/docs/getting-started/deployment/) for detailed hardware recommendations with prices.

### Does it work on a phone?

**Yes, but it is not ideal.** Beacon has a mobile-responsive layout with a bottom tab bar. It works on phones, but the experience is designed for landscape tablets and wall-mounted displays. On phones, the calendar week view is cramped and some features are behind the "More" menu.

### Is there an Android app?

**Yes, as a sideloaded APK.** Every release since v1.42.0 attaches a signed `beacon-vX.Y.Z.apk` and its checksum. It isn't in the Play Store yet. The app talks to your Home Assistant server directly, so use your Home Assistant URL on first launch. See [Install the Android app](/docs/getting-started/android/). A browser in kiosk mode (Fully Kiosk Browser) still works too.

### Does it work in portrait mode?

Beacon is designed for **landscape displays** (16:9 or 16:10). In portrait mode, the layout works but some views (especially the week calendar) are not optimized for the narrower width.

### What screen size works best?

8" to 15" is the sweet spot. The UI is readable from across a room on a 10" display. Larger displays (15-24") work great with a Raspberry Pi or mini PC.

## Features

### Can I show photos like Skylight?

**Yes.** Beacon has a built-in photo frame with slideshow, crossfade transitions, clock/date overlay, and music controls on top. Photos can come from your HA media directory, any Home Assistant media folder (Immich, a NAS), or Google Photos shared-album links (1.44.0 and later). See [Photos](/docs/features/photos/).

### Does it have a dark mode?

**Yes.** Beacon ships with 7 themes, including 4 dark themes: Midnight, Dracula, Monokai, and (partially dark) Nord. There is also an "Auto" mode that switches between Skylight (light) and Midnight (dark) based on time of day. See [Themes](/docs/customization/themes/). To dim the wall on a schedule, see [Night mode](/docs/features/night-mode/).

### Can Beacon dim the screen at night?

**Yes, from 1.50.0.** Open **Settings → Display → Night mode** and turn it on. It is off by default. You set start and end times in the device's local clock (overnight windows work; the default is 9:00 PM to 6:30 AM), or use a manual On or Off override. While it is on, Beacon switches to the Midnight theme and dims the dashboard with an overlay. An optional Clock only screen shows a large clock and the date. A tap brings the dashboard back for 60 seconds. A finished countdown timer wakes the screen and holds it until the alarm is dismissed, for at least 60 seconds. Beacon does not ship a plugin that changes the tablet's hardware brightness; a typical install only uses the overlay. This is separate from the idle [Screen Saver](/docs/features/screensaver/). See [Night mode](/docs/features/night-mode/).

### Can multiple family members use it?

**Yes.** Add up to 8 family members with custom avatars, colors, and roles. Each member's chores and streaks are tracked independently. The leaderboard shows earnings per member. See [Family Members](/docs/features/family/).

### Can a babysitter use Beacon without full access?

**Yes, from 1.51.0.** Set a guest PIN under **Settings → Display → Guest mode**. It is empty by default. The same hidden-corner gesture plus that PIN starts guest mode, and a **Guest** badge stays on the screen. Guest mode hides Settings, family and rewards changes, Magic Import, event create/edit/delete, and calendars marked **Hide from guests**. Meals, photos, music, and the leaderboard stay visible. A guest can still check off chores and tasks, add grocery items, and use timers. Chores they check off still count for points and streaks, and show **Checked off by Guest** on chore rows (Home Assistant to-do items don't get the label). From 1.52.0, an unassigned guest check-off is recorded as Guest and earns no points. Guests can earn rewards but cannot redeem them. Guests can always leave guest mode from inside the app: a family PIN leaves it, or the guest PIN when no family PIN is set. Guest mode only limits what this Beacon screen shows. It is not a security boundary. Home Assistant and the API stay reachable on the network. See [Guest mode](/docs/features/guest-mode/).

### Can kids earn money for doing chores?

**Yes.** Each chore can have a dollar value (e.g., $1.00). When a family member completes a chore, the value is tracked. The Leaderboard shows total earnings by week or month. See [Chores](/docs/features/chores/).

### Can Beacon turn off Wi-Fi or the TV until chores are done?

**Yes, from 1.45.0.** For each child, pick a Home Assistant switch, input boolean, light, or fan under **Settings > Family Members**. Beacon turns that entity on when the child finishes today's chores, and off when a chore is unchecked, at the chore reset time (local midnight when that time is unset), and when Beacon restarts. Existing settings are left as they are. See [Chore privileges](/docs/features/chore-privileges/).

### Can I talk to Beacon?

**Yes, from 1.46.0.** The wall has a hold-to-talk button under **Settings > Display > Voice button**. The microphone only works when Beacon is opened over HTTPS or on localhost; many wall tablets use plain HTTP, and on those only the text box shows. Phrases like "Mark X as done" complete a chore in Beacon's chore chart. See [Press-to-talk](/docs/features/press-to-talk/).

### Can I control music from the display?

**Yes.** Beacon controls any media player entity in Home Assistant — Sonos, Google Home, Music Assistant, Chromecast, etc. You get play/pause, skip, volume, album art, and a progress bar. A "Now Playing" bar appears on all views when music is active. See [Music](/docs/features/music/).

### Can I set timers?

**Yes.** Beacon has a built-in timer with countdown (1, 5, 10, 15, 30 minute presets) and stopwatch modes. The countdown plays an audio alert when finished. See [Timer](/docs/features/timer/).

### Can Beacon plan our meals?

**Yes, from 1.48.0.** Open **Meals** in the sidebar for a week grid of Breakfast, Lunch, Dinner, and Snack, or edit today from the dashboard Menu card (the card stays visible when nothing is planned yet). You can name a meal, add notes, tie it to a Beacon recipe, and add that recipe's ingredients to the grocery list. An assistant can also set meals through Beacon's MCP server: by default it adds or updates only the meals you send, and a null or empty name clears that one slot. See [Meals](/docs/features/meals/).

### Does it have a grocery list?

**Yes.** The Grocery view shows Home Assistant to-do lists, including AnyList lists. You can view the list, add items, and check them off. See [Grocery](/docs/features/grocery/).

### Does Beacon work with Grocy?

**Yes, from 1.52.0, through the [HACS Grocy integration](https://github.com/custom-components/grocy).** Open **Settings → Integrations → Grocy**. **Grocy Integration** lets [Magic Import](/docs/features/magic-import/) add items to Grocy's shopping list. Optional **Expiring products** and **Low stock** dashboard cards (off by default) read `binary_sensor.grocy_expiring_products` and `binary_sensor.grocy_missing_products`. From 1.52.1, with Grocy Integration on, the Grocery screen includes a list named Grocy and check-offs on that list write the shopping-list done flag. The expiring card shows only items due within 3 days. Beacon does not sync Grocy chores or Grocy's meal plan; it has its own [chores](/docs/features/chores/) and [meal planner](/docs/features/meals/). See [Grocery](/docs/features/grocery/).

### Does it send notifications?

**Yes.** Beacon monitors upcoming calendar events and sends notifications ahead of each event through two channels:

1. **Browser push notifications** (requires one-time permission grant)
2. **Home Assistant mobile app notifications** via `notify.notify`

By default, notifications fire 10 minutes before timed events (not all-day events). You can customize the timing in **Settings > Calendar** to 5, 10, 15, or 30 minutes. Beacon checks every minute and sends each notification once per event.

See [Notifications](/docs/features/notifications/) for setup details, permission requirements, and troubleshooting.

### Does it prevent screen burn-in?

**Yes.** After 5 minutes of inactivity, the screen dims. After 10 minutes, a clock screensaver appears that repositions every 30 seconds to prevent burn-in. See [Screen Saver](/docs/features/screensaver/).

## Setup and Configuration

### How do I change the theme?

Click the palette icon at the bottom of the sidebar. A dropdown shows all 7 themes plus Auto mode. Click to apply immediately. See [Themes](/docs/customization/themes/).

### How do I change the family name?

Set the `family_name` option in the add-on configuration, or the `VITE_FAMILY_NAME` environment variable in development. See [Configuration](/docs/customization/configuration/).

### How do I change the weather entity?

Set the `weather_entity` option to your HA weather entity ID (e.g., `weather.home`). Find your entity ID in **Settings > Devices & Services > Entities**. See [Configuration](/docs/customization/configuration/).

### How do I connect multiple calendars?

Add multiple calendar integrations in Home Assistant (Google Calendar, CalDAV, Local Calendar, etc.). Beacon discovers all `calendar.*` entities automatically. Use the filter pills above the calendar to show/hide specific calendars.

### How do I set up family members?

Click the gear icon in the sidebar to open the Family Members modal. Click "+ Add Member" and fill in the name, avatar, color, role, and optional PIN. See [Family Members](/docs/features/family/).

### How do I hide the sidebar for wall tablets / kiosk setups?

**Beacon's own sidebar**: Enable **Kiosk Mode** in **Settings > Display**. This hides Beacon's sidebar entirely and uses a full-width layout. (Fixed in [PR #51](https://github.com/asachs01/beacon/pull/51) — earlier versions had a non-functional toggle.)

Nothing is shown until you reveal it. **Reveal navigation gesture** (same screen, on by default) is the way back:

- **Touch or mouse**: long-press the top corner for about 2 seconds, or tap that corner 3 times quickly. The corner is the top-left, or the top-right when the sidebar position is set to the right.
- **Keyboard**: hold Escape for about 2 seconds (outside a text field). You can also focus the same corner and hold Enter or Space, or press it 3 times quickly.

The sidebar stays up for about 15 seconds after the last tap, click, or key press, then hides again. If any family member has a PIN, Beacon asks for that PIN before showing navigation. The same gesture can also start [guest mode](/docs/features/guest-mode/) when a guest PIN is set; the guest PIN never reveals navigation. Turn the gesture off under **Settings > Display** when this screen should stay locked with no way back from the display itself.

**Kid Display** is a different mode (one child's routines and chores). The same corner gesture — long-press or 3 quick taps, or holding Escape — is the way out. When a family PIN is set, it is required. When no PIN is set, Beacon asks you to confirm. Five taps on the clock still opens that same PIN or confirm step.

**Home Assistant's sidebar** (when running as an HA add-on): Beacon cannot hide HA's sidebar when running inside Home Assistant ingress — that chrome is controlled by Home Assistant itself. For dedicated wall tablets or Windows kiosk setups, open Beacon's direct URL in full-screen mode instead:

1. **Find the direct URL**: In HA, click "Open Web UI" on the Beacon add-on page, or use the direct ingress URL (typically `http://YOUR_HA_IP:8123/api/hassio_ingress/<addon-token>`)
2. **For Android tablets**: Use [Fully Kiosk Browser](/docs/getting-started/installation/#mounting-and-displaying-on-a-tablet) with "Hide Navigation Bar" and "Hide Status Bar" enabled
3. **For desktop/Pi kiosk**: Launch Chrome/Chromium with `--kiosk` flag pointed at the Beacon URL
4. **For standalone Docker**: Use the container's direct URL (e.g., `http://YOUR_DOCKER_HOST:3000`)

See the [Installation guide](/docs/getting-started/installation/#mounting-and-displaying-on-a-tablet) for detailed kiosk setup instructions.

## Updates and Maintenance

### Is my data preserved across updates?

**Yes.** On the add-on, family members, chores, routines, settings and meal plans are saved by Beacon's server in the add-on's `/data` folder, and the display keeps a copy in the browser. Updates don't touch `/data`.

On Docker, your data survives only if you mounted a volume at `/data`, for example `-v beacon-data:/data`. See [Updating and Troubleshooting](/docs/getting-started/updating/#docker).

### Can I back up my data?

**Yes.** On the add-on, Beacon's data is included in Home Assistant backups (**Settings → System → Backups**). On Docker, back up the volume you mounted at `/data`.

## Troubleshooting

### Beacon shows "Demo Mode"

This means Beacon cannot connect to Home Assistant. Check:
1. The HA token is configured (add-on: automatic; Docker or Kubernetes: `HA_URL` and `HA_TOKEN`, a long-lived access token, from **1.50.1**; dev: `VITE_HA_TOKEN`)
2. On a standalone container, `HA_URL` is the Home Assistant base URL and is reachable from the container. The browser only needs to reach Beacon. In development, the browser must be able to reach `VITE_HA_URL`.
3. Home Assistant is running. If `HA_URL` or `HA_TOKEN` is missing on a standalone container, the UI still loads but has no Home Assistant data, and the log says `Standalone mode needs HA_URL and HA_TOKEN`.

### Calendar is empty

1. Verify calendar integrations are configured in HA
2. Check that `calendar.*` entities exist in **Developer Tools > States**
3. Wait up to 5 minutes for the initial data fetch, or reload the page

### Everything is slow on my old tablet

1. Use a dark theme (fewer bright pixels = less power on OLED/AMOLED)
2. Close other apps and browser tabs
3. Consider using a simpler browser like Chrome instead of a full-featured one
4. Increase the photo interval and screen saver timeout to reduce UI updates

### Something else is broken

1. Check the browser console (F12) for error messages
2. Check the add-on logs (**Settings > Add-ons > Beacon > Log**)
3. Check [Updating and Troubleshooting](/docs/getting-started/updating/) for known problems
4. Open a [GitHub issue](https://github.com/asachs01/beacon/issues) with your HA version, browser, device, and relevant logs
