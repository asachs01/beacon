# Frequently Asked Questions

---

## General

### Does this work with Google Calendar?

**Yes.** Beacon reads calendar data through Home Assistant's Google Calendar integration. Set up the integration once in HA, and Beacon automatically discovers your calendars. See the [Getting Started guide](/docs/getting-started/installation/) for step-by-step instructions.

Beacon also works with **any calendar source** Home Assistant supports, including CalDAV (Nextcloud, iCloud, Fastmail), ICS feeds, and the built-in Local Calendar.

### Can I create and edit events from the display?

**Yes.** Beacon supports full CRUD operations on calendar events. Tap the + button or a time slot to create events. Tap an existing event to edit or delete it. You can even drag events to reschedule them. See [Calendar](/docs/features/calendar/).

### Does Beacon send my data anywhere?

The Family add-on/Docker server keeps HA credentials out of the browser. Beacon itself does not require a Beacon cloud account, but Home Assistant integrations such as Google Calendar or Google Tasks may communicate with external providers you have configured.

Data flow: `Google/CalDAV -> Home Assistant -> Beacon (local only)`

### Is there a subscription?

**No.** Beacon is free and open-source under the MIT license. No subscriptions, no premium tiers, no free trial.

### Can I use this without Home Assistant?

The development UI can display local/demo content, but HA integrations such as calendars, weather, and media players require Home Assistant. "Standalone Docker" means without **Supervisor**, not without Home Assistant. If you do not have HA, [HA OS](https://www.home-assistant.io/installation/) is an option.

## Hardware

### What hardware do I need?

1. **A Home Assistant instance** (HA OS on a Pi, NUC, or VM)
2. **A display device** with a web browser (any tablet, old monitor + mini PC, etc.)

The cheapest complete setup is a $35 Fire HD 8 with a $15 magnetic mount — under $50.

See [Deployment](/docs/getting-started/deployment/) for detailed hardware recommendations with prices.

### Does it work on a phone?

**Yes, but it is not ideal.** Beacon has a mobile-responsive layout with a bottom tab bar. It works on phones, but the experience is designed for landscape tablets and wall-mounted displays. On phones, the calendar week view is cramped and some features are behind the "More" menu.

### Does it work in portrait mode?

Beacon is designed for **landscape displays** (16:9 or 16:10). In portrait mode, the layout works but some views (especially the week calendar) are not optimized for the narrower width.

### What screen size works best?

8" to 15" is the sweet spot. The UI is readable from across a room on a 10" display. Larger displays (15-24") work great with a Raspberry Pi or mini PC.

## Features

### Can I show photos like Skylight?

**Yes.** Beacon has a built-in photo frame with slideshow, crossfade transitions, clock/date overlay, and music controls on top. Add photos to your HA media directory and configure the photo directory. See [Photos](/docs/features/photos/).

### Does it have a dark mode?

**Yes.** Beacon ships with 7 themes, including 4 dark themes: Midnight, Dracula, Monokai, and (partially dark) Nord. There is also an "Auto" mode that switches between Skylight (light) and Midnight (dark) based on time of day. See [Themes](/docs/customization/themes/).

### Can multiple family members use it?

**Yes.** Add up to 8 family members with custom avatars, colors, and roles. Each member's chores and streaks are tracked independently. The leaderboard shows earnings per member. See [Family Members](/docs/features/family/).

### Can kids earn money for doing chores?

**Yes.** Each chore can have a dollar value (e.g., $1.00). When a family member completes a chore, the value is tracked. The Leaderboard shows total earnings by week or month. See [Chores](/docs/features/chores/).

### Can I control music from the display?

**Yes.** Beacon controls any media player entity in Home Assistant — Sonos, Google Home, Music Assistant, Chromecast, etc. You get play/pause, skip, volume, album art, and a progress bar. A "Now Playing" bar appears on all views when music is active. See [Music](/docs/features/music/).

### Can I set timers?

**Yes.** Beacon has a built-in timer with countdown (1, 5, 10, 15, 30 minute presets) and stopwatch modes. The countdown plays an audio alert when finished. See [Timer](/docs/features/timer/).

### Does it have a grocery list?

**Yes.** Beacon integrates with Grocy and AnyList through Home Assistant. You can view your shopping list, add items, check them off, and see expiring product alerts. See [Grocery](/docs/features/grocery/).

### Does it send notifications?

**Yes.** Beacon sends browser push notifications and HA mobile app notifications 15 minutes before calendar events. See [Notifications](/docs/features/notifications/).

### Does it prevent screen burn-in?

**Yes.** After 5 minutes of inactivity, the screen dims. After 10 minutes, a clock screensaver appears that repositions every 30 seconds to prevent burn-in. See [Screen Saver](/docs/features/screensaver/).

## Setup and Configuration

### How do I change the theme?

Click the palette icon at the bottom of the sidebar. A dropdown shows all 7 themes plus Auto mode. Click to apply immediately. See [Themes](/docs/customization/themes/).

### How do I change the weather entity?

In the add-on, set the `weather_entity` option to your HA weather entity ID (e.g., `weather.home`). In standalone Docker, set `WEATHER_ENTITY` as a non-secret startup default or choose it in Beacon's settings. Include that exact entity in `allowed_entities`/`BEACON_ALLOWED_ENTITIES`. Find the ID in **Settings > Devices & Services > Entities** in HA. See [Configuration](/docs/customization/configuration/).

### How do I connect multiple calendars?

Add multiple calendar integrations in Home Assistant (Google Calendar, CalDAV, Local Calendar, etc.). List their exact `calendar.*` entity IDs in `allowed_entities` (add-on) or `BEACON_ALLOWED_ENTITIES` (Docker); Beacon discovers only allowed entities. Show or hide specific calendars in **Settings > Calendar**.

### How do I set up family members?

Click the gear icon in the sidebar to open the Family Members modal. Click "+ Add Member" and fill in the name, avatar, color, role, and optional PIN. See [Family Members](/docs/features/family/).

### Why did parent controls lock while the app was open?

A parent session expires **10 minutes after the PIN is entered**, even when the app is active or polling. Re-enter the configured 6–8 digit add-on `parent_pin` or standalone `BEACON_PARENT_PIN` to continue privileged actions. Kid Display sessions instead slide for **24 hours from their most recent session poll**. Neither session replaces HA ingress login or Docker's HTTP Basic password.

## Updates and Maintenance

### How do I update Beacon?

**Add-on**: Go to **Settings > Add-ons > Family** and click **Update** if available. Supervisor builds it from this fork's root Dockerfile; the standalone image does not replace that add-on.

**Docker**: Choose a newer **published version** from [the fork's GHCR package](https://github.com/f1f1f1f1f1f1/Family/pkgs/container/family), then pull and recreate the container, keeping the same `/data` volume:
```bash
docker pull ghcr.io/f1f1f1f1f1f1/family:vX.Y.Z
docker stop family && docker rm family
docker run -d --name family --restart unless-stopped \
  -p 127.0.0.1:3000:3000 --env-file /secure/path/family.env \
  -v family-data:/data ghcr.io/f1f1f1f1f1f1/family:vX.Y.Z
```

Replace `vX.Y.Z` with the actual new tag; there is no `latest` tag.

### Is my data preserved across updates?

**Add-on**: Yes. Configuration and family data in the add-on's `/data` directory are preserved across updates.

**Standalone Docker**: Mount and retain a volume at `/data`; otherwise deleting the container can delete stored family data. Home Assistant entities remain in HA.

**Browser data**: localStorage stores display preferences and caches. Clearing it may reset preferences, but the server-backed family data will be refreshed from `/data` when available.

### Can I back up my data?

Use Home Assistant's add-on backup for the Supervisor-built add-on. For Docker, back up the volume mounted at `/data` and your Home Assistant data. Browser-only preferences may be lost when clearing a display's site data.

Do not rely on a browser localStorage export as the primary backup of server-backed collections.

## Troubleshooting

### Beacon loads without HA data

Check:
1. Home Assistant is running. In Docker, the server has `HA_URL` reachable **from its container** and a valid server-only `HA_TOKEN`; in the add-on, check Supervisor connectivity and authenticated HA ingress.
2. Standalone HTTP Basic username `beacon` and password `BEACON_PASSWORD` are configured; the separate parent PIN unlocks privileged actions as described in [Configuration](/docs/customization/configuration/).
3. `allowed_entities` (add-on) or `BEACON_ALLOWED_ENTITIES` (Docker) lists **exact** IDs for the calendars, todo lists, weather entities and media players Family needs. An empty list denies HA entity/service access. Check logs for denied calls; do not put an HA token in `VITE_HA_TOKEN` or `runtime-config.js` to work around missing data.

For direct development/native login, use the app's onboarding flow rather than a token bundled into Vite.

If an earlier build used `VITE_HA_TOKEN` or stored a long-lived HA token in your browser, **revoke and replace that token** from your HA profile. New server-backed sessions delete the browser copy, but cannot undo past exposure.

### Calendar is empty

1. Verify calendar integrations are configured in HA
2. Check that `calendar.*` entities exist in **Developer Tools > States**
3. Wait up to 5 minutes for the initial data fetch, or reload the page

### Everything is slow on my old tablet

1. Use a dark theme (fewer bright pixels = less power on OLED/AMOLED)
2. Close other apps and browser tabs
3. Consider using a simpler browser like Chrome instead of a full-featured one
4. Increase the photo interval and screen saver timeout to reduce UI updates

### Something else is broken

1. Check the browser console (F12) for error messages
2. Check the add-on logs (**Settings > Add-ons > Family > Log**) or `docker logs family`
3. Open a [GitHub issue in this fork](https://github.com/f1f1f1f1f1f1/Family/issues) with your HA version, browser, device, and relevant **redacted** logs (never share tokens or passwords)
