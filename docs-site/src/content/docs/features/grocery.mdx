# Grocery

The Grocery view shows shopping lists from Home Assistant to-do entities, including AnyList lists. With **Grocy Integration** on, it also shows a list named **Grocy** beside those lists. Beacon talks to [Grocy](https://grocy.info/) through the HACS Grocy integration: you can add, check, and uncheck items on that list, add items with [Magic Import](/docs/features/magic-import/), and turn on optional dashboard cards for expiring and low-stock products.

A guest in [guest mode](/docs/features/guest-mode/) can still add items to the grocery list.

This needs Beacon **1.52.0** or later. A Grocy list on the Grocery screen, and check-offs that write back to Grocy, need **1.52.1** or later.

---

## How lists are chosen

The Grocery view in the sidebar manages Home Assistant to-do lists and local lists. With **Grocy Integration** on, it adds a list named **Grocy** next to those lists. It does not replace them. Turn the integration off and the Grocery screen is unchanged: only the Home Assistant and local lists remain.

From **1.52.1**, a **Shopping** card on the [advanced dashboard](/docs/features/dashboard/) also shows a **Grocy** section when the integration is on, with the same add and check-off path as the Grocery screen. That card lists unchecked Grocy items. The default Family and Classic layouts do not include a Shopping card; you add it in dashboard edit mode. When the integration is off, the Shopping card stays on its Home Assistant to-do list, if one is set.

Checking, unchecking, or adding on the Grocy list writes to Grocy (`grocy.update_generic` with `{ done: 1 }` or `{ done: 0 }`, or `grocy.add_generic`). Those actions do not add the product to stock and do not call the Home Assistant todo services. A failed write shows “Couldn't update the Grocy shopping list.” Other lists on that screen keep their Home Assistant or local paths.

For AnyList, Beacon looks for `todo.anylist_*` entities. If no list is available, the grocery screen shows a message to connect a service.

Two optional dashboard cards, both off by default, live in the same Grocy settings group: **Expiring products** and **Low stock**. Each card stays hidden when its Home Assistant entity is missing. The expiring card lists only products whose `best_before_date` falls within 3 days. Grocy's due-products sensor can use a longer window; Beacon filters that attribute. Older setups that still expose `sensor.grocy_expiring_products` use the same filter. See [Grocy](#grocy).

## Grocy

Grocy support requires the HACS integration [custom-components/grocy](https://github.com/custom-components/grocy). Install that integration, then enter your Grocy URL and API key there. Grocy itself can run as a Home Assistant add-on or as its own install; Beacon talks only to the integration's entities and services.

### Settings

Open **Settings → Integrations → Grocy**. All three switches start off.

- **Grocy Integration** — shows a **Grocy** list on the Grocery screen and lets [Magic Import](/docs/features/magic-import/) add items to Grocy. The Grocy client stays on Grocy when this is on, even if the list is empty, instead of falling through to AnyList.
- **Expiring products** — a dashboard card that reads `binary_sensor.grocy_expiring_products` (or the older id `sensor.grocy_expiring_products`) and keeps products whose `best_before_date` is within 3 days.
- **Low stock** — a dashboard card that reads `binary_sensor.grocy_missing_products` (or the older id `sensor.grocy_missing_products`).

If a card's entity is missing, that card is not shown.

### Shopping-list client

Beacon's Grocy client reads the shopping list from `sensor.grocy_shopping_list` (the `products` attribute). Product names come from the row's product data (or `sensor.grocy_stock`), then the item's note, then `Product #<id>` if neither is available.

- Adding an item calls `grocy.add_generic` with `entity_type: shopping_list` and `{ note, amount: 1 }`. It does not purchase or stock the product. The Grocery screen uses this for the Grocy list. Magic Import uses it when the destination list is Grocy.
- Checking or unchecking an item calls `grocy.update_generic` with `entity_type: shopping_list`, the item's `object_id`, and `{ done: 1 }` or `{ done: 0 }`. That only sets the shopping-list done flag. It does not add the product to stock. From **1.52.1**, the Grocery screen uses these calls for the Grocy list. Home Assistant and local lists on that screen are unchanged.
- If a Grocy write fails, Beacon shows the toast **Couldn't update the Grocy shopping list.**

### What is not in this version

Beacon does not sync Grocy chores or Grocy's meal plan. Beacon already has its own [chores](/docs/features/chores/) and [meal planner](/docs/features/meals/). Adding recipe ingredients to a grocery list writes to the default list or the built-in Shopping List (including Home Assistant to-do lists); it does not write to Grocy.

## Behavior changes

In **1.52.0**:

- [Magic Import](/docs/features/magic-import/) can add items to Grocy when **Grocy Integration** is on.
- Optional **Expiring products** and **Low stock** cards can be turned on under **Settings → Integrations → Grocy**.
- The Grocery screen still showed only Home Assistant and local lists. Checking an item off there updated that list, not Grocy.

In **1.52.1**:

- With **Grocy Integration** on, a list named **Grocy** appears on the Grocery screen next to the existing lists, and check-offs on that list write to Grocy.
- The expiring card shows only items due within 3 days. It stays hidden when the sensor is missing, and it still accepts the older `sensor.grocy_expiring_products` id.

## Grocy setup

### Step 1: Install Grocy

If you do not already have Grocy running:

1. Install the **Grocy** add-on from the Home Assistant Add-on Store, or run Grocy on its own
2. Complete the initial Grocy setup through its web UI
3. Add some products and a shopping list

### Step 2: Install the HACS Grocy integration

1. Install [custom-components/grocy](https://github.com/custom-components/grocy) through HACS (Home Assistant Community Store)
2. Restart Home Assistant
3. Go to **Settings > Devices & Services**
4. Click **Add Integration** and search for **Grocy**
5. Enter your Grocy URL and API key (found in Grocy's settings)
6. Click **Submit**

### Step 3: Verify the entities

After the integration is set up, verify these entities exist in **Developer Tools > States**:

- `sensor.grocy_shopping_list` — shopping list items (`products`)
- `binary_sensor.grocy_expiring_products` — products nearing their best-before date (`expiring_products`). Older setups may still expose `sensor.grocy_expiring_products`.
- `binary_sensor.grocy_missing_products` — products under minimum stock (`missing_products`). Older setups may still expose `sensor.grocy_missing_products`.

### Step 4: Turn Grocy on in Beacon

Open **Settings → Integrations → Grocy**. Turn on **Grocy Integration** so Magic Import can add items and the Grocery screen includes a **Grocy** list. Turn on **Expiring products** and **Low stock** if you want those cards on the dashboard.

Open the Grocery view (shopping cart icon in the sidebar). The list selector includes **Grocy** alongside your Home Assistant lists.

## AnyList integration setup

[AnyList](https://www.anylist.com/) is a shared grocery list app. Since AnyList has no official public API, the integration works through a custom Home Assistant integration.

### Step 1: Install the AnyList integration

1. Install the [AnyList custom component](https://github.com/kevdliu/hacs-anylist) via HACS (Home Assistant Community Store)
2. Restart Home Assistant
3. Go to **Settings > Devices & Services**
4. Click **Add Integration**
5. Search for **AnyList**
6. Enter your AnyList email and password
7. Click **Submit**

### Step 2: Verify the entities

The integration creates `todo.anylist_*` entities for each of your AnyList lists:

- `todo.anylist_grocery` — your main grocery list
- `todo.anylist_costco` — other lists you have in AnyList

### Step 3: Open Beacon

Navigate to the Grocery view. You should see your AnyList items. Beacon uses the first discovered AnyList entity as the primary list when it is choosing among AnyList lists.

## Using the shopping list

### Opening the grocery view

Click the **shopping cart icon** in the sidebar. On mobile, tap **More** then **Grocery**.

The grocery screen shows:

1. **List selector**: Home Assistant and local lists. With Grocy Integration on, a **Grocy** list is included too.
2. **Quick-add input**: a text field to add new items. On the Grocy list this calls `grocy.add_generic`.
3. **Shopping list**: unchecked items first, then checked items. Checking a Grocy item writes the shopping-list `done` flag. Other lists stay on their Home Assistant or local path.

### Quick-add items

1. Tap the text input at the top of the list
2. Type the item name (e.g., "Milk")
3. Tap **Add** or press Enter
4. The item is added to the selected list. A Home Assistant list uses `todo.add_item`. The Grocy list uses `grocy.add_generic`.

You can also paste a list (or a message that includes one), or add a photo or PDF, with [Magic Import](/docs/features/magic-import/). Review the draft items, then approve them. Pasted text is processed by your Home Assistant conversation agent, or a local parser. Photos and scanned PDFs are processed by your Home Assistant AI Task entity. When **Grocy Integration** is on, Magic Import can send a draft item to Grocy.

### Checking off items

1. Tap any item in the list
2. If unchecked, it becomes checked
3. If already checked, tapping unchecks it

Updates are optimistic — the UI updates immediately while the API call happens in the background. On the Grocy list, that call is `grocy.update_generic` with `{ done: 1 }` or `{ done: 0 }`. It does not add the product to stock. A failed write shows **Couldn't update the Grocy shopping list.** and puts the check back. Home Assistant and local lists are unchanged.

### Item details

Each item may show:
- **Name**: The item name
- **Quantity**: Number or amount (if set)
- **Category**: Product category or group (if available)

## Expiring and low-stock cards

When **Expiring products** or **Low stock** is on under **Settings → Integrations → Grocy**, Beacon shows that card on the dashboard sidebar. The expiring card reads `expiring_products` and keeps products whose `best_before_date` is within the next 3 days. Products with no date, or a date further out, stay off the card. The low-stock card lists products below their minimum stock. An empty sensor still shows the card, with **Nothing expiring soon** or **Nothing low or missing**. If the entity is not in Home Assistant, the card is hidden. Older setups that still expose `sensor.grocy_expiring_products` or `sensor.grocy_missing_products` use those ids.

These cards are only available with Grocy. AnyList does not track expiration dates or minimum stock in Beacon.

---

## Meal plan display

Today's meals show in the dashboard's **Menu** widget, not on the grocery screen. Beacon does not read Grocy's meal plan (`sensor.grocy_meal_plan`) into that widget. See [Meals](/docs/features/meals/) for how to get meals onto the display.

---

## Data refresh

- Home Assistant grocery lists refresh automatically every 30 seconds
- The Grocy list refreshes automatically every 2 minutes
- Adding, checking, or unchecking an item triggers a refresh
- The expiring products card reads the Grocy sensor on its own schedule

## Troubleshooting

### "No lists available"

The Grocery view shows this when it cannot find a Home Assistant or local shopping list to open. Verify:

1. A Home Assistant to-do list or `todo.anylist_*` entity exists, and **Settings → Integrations** points Beacon at the right lists if you have set them
2. Beacon is connected to Home Assistant (no "Connecting..." badge)

An empty list shows **No items yet — add one above**. With **Grocy Integration** on, the **Grocy** list is still in the selector even when `sensor.grocy_shopping_list` is empty.

### Items do not sync back to Grocy

Check-offs sync to Grocy only on the **Grocy** list, and only when **Grocy Integration** is on. Home Assistant and local lists on the same screen stay on their own paths. Adds that go through Magic Import when Grocy is the destination call `grocy.add_generic`. If a Grocy write fails, look for the toast **Couldn't update the Grocy shopping list.** Also check:

1. The Home Assistant token is valid
2. The HACS Grocy integration is functioning (check **Developer Tools > States** for the entity)
3. **Grocy Integration** is on under **Settings → Integrations → Grocy**
4. You are checking an item on the **Grocy** list, not a Home Assistant to-do list

### Expiring or low-stock cards do not appear

1. Turn on **Expiring products** or **Low stock** under **Settings → Integrations → Grocy**
2. Verify `binary_sensor.grocy_expiring_products` or `binary_sensor.grocy_missing_products` exists (or the older `sensor.*` ids)
3. For expiring products, ensure products in Grocy have best-before dates set. The card only lists products whose `best_before_date` is within the next 3 days

### AnyList shows wrong list

Beacon uses the first `todo.anylist_*` entity it discovers. If you have multiple AnyList lists, the one that appears depends on the order HA returns entities. To ensure the correct list is used, you may need to rename entities in HA.

### Quick-add does nothing

1. Make sure the input is not empty (whitespace-only is rejected)
2. Check the browser console for errors
3. Verify the underlying service (`todo.add_item`, or `grocy.add_generic` when adding to Grocy) works by calling it from **Developer Tools > Services** in HA
