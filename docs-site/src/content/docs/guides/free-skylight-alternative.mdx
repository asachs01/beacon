# Free Skylight alternative

Beacon is a free, MIT-licensed alternative to Skylight Calendar that installs as a Home Assistant add-on and runs in any tablet's browser or as a signed Android app. You do not buy a proprietary display, and you do not pay for Calendar Plus. The shared calendar, chores, and photos are included. Beacon has an [in-app meal planner](/docs/features/meals/) ([v1.48.0](https://github.com/asachs01/beacon/releases/tag/v1.48.0)) with a week grid for breakfast, lunch, dinner, and snacks (it follows Settings → General → Week Starts On), an editable dashboard Menu card (including on empty days), and Beacon recipes. Add ingredients to grocery list writes to the default list or the built-in Shopping List, including Home Assistant to-do lists, not Grocy. You can still fill the plan from the AnyList sync or the MCP meal tools.

This is a practical switch-over path. The feature-by-feature comparison lives on [Beacon vs Skylight](/docs/getting-started/skylight-alternative/) and [Beacon vs Skylight, Hearth, and DAKboard](/docs/getting-started/compare/).

## 1. Confirm it is the right swap

Read the [Beacon vs Skylight](/docs/getting-started/skylight-alternative/) page first. Beacon fits if you already run Home Assistant (or will) and want a wall tablet without a subscription. Skylight still makes sense if you want a sealed consumer display with vendor support.

Skylight's help center states that [Calendar Plus costs $79 per year](https://skylight.zendesk.com/hc/en-us/articles/35984779668379-What-does-a-Skylight-Calendar-cost) and that [meal planning, recipes, photo screensaver, and related extras require Plus](https://skylight.zendesk.com/hc/en-us/articles/57326775089691-Calendar-Plus). [Basic calendar, chores, and lists work on Skylight without a subscription](https://skylight.zendesk.com/hc/en-us/articles/36009559376795-Does-Skylight-Calendar-require-a-subscription).

## 2. Install Beacon

Install the Home Assistant add-on, or run the Docker container, using the [Getting Started](/docs/getting-started/installation/) guide.

## 3. Connect the calendars you already use

Sync the same family calendars you used on Skylight, or start with Beacon's local calendar. [First-time setup](/docs/getting-started/installation/#first-time-setup) walks through both. Then add [family members](/docs/features/family/) so everyone has a color on the [calendar](/docs/features/calendar/) and [dashboard](/docs/features/dashboard/).

## 4. Mount a wall tablet

Open Beacon in the tablet's browser, or [sideload the signed Android APK from GitHub releases](/docs/getting-started/android/) (not on Play Store yet), and lock it in kiosk mode. [Set up a wall tablet as a family calendar](/docs/guides/wall-tablet-family-calendar/) points to the existing mounting and kiosk docs.
