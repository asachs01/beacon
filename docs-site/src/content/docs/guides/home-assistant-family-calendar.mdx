# Home Assistant family calendar dashboard

Beacon is a free, MIT-licensed family calendar dashboard that installs as a Home Assistant add-on and runs in any tablet's browser. Connect the calendar entities you already have in Home Assistant (or use Beacon's local calendar), add family members, and put the week on a wall display — there is no subscription.

This page is a short path through the existing docs, not a second install guide.

## 1. Install the add-on

Add the Beacon repository in Home Assistant, install the add-on, and open the web UI. The [Getting Started](/docs/getting-started/installation/) guide has the one-click badge and the manual steps, plus a standalone Docker option if you are not using the add-on.

## 2. Connect your calendars

Point Beacon at your Home Assistant calendar entities, or set up the built-in local calendar if you do not use Google or another provider. Both paths are in [First-Time Setup](/docs/getting-started/installation/#first-time-setup). The [Calendar](/docs/features/calendar/) page covers the week view, recurring events, and filtering.

## 3. Add family members and the dashboard

Create family members so events and chores are color-coded, then use the dashboard as the always-on view. See [Family Members](/docs/features/family/) and [Dashboard](/docs/features/dashboard/).

## 4. Put it on a wall display

Open Beacon in the tablet's browser and, if you want a locked kiosk, follow the mounting and kiosk notes in the [installation](/docs/getting-started/installation/#mounting-and-displaying-on-a-tablet) and [deployment](/docs/getting-started/deployment/#kiosk-mode-setup) guides. There is also a shorter walkthrough: [Set up a wall tablet as a family calendar](/docs/guides/wall-tablet-family-calendar/).
